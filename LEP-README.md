# LEP — логика работы программы (актуальная версия)

Этот файл — источник правды по тому, как должна работать программа.
Обновляется при каждом изменении логики. Хранить в одной папке с
модулями LEP-*.LSP.

## Общий порядок работы

1. Открываем новый чертёж AutoCAD.
2. Вставляем подложку — скриншот кадастровой карты (`IMAGEATTACH`).
3. Загружаем программу: `APPLOAD` → `LEP-START.LSP`.
4. `LEP-SCALE` — по двум точкам на подложке с известным реальным
   расстоянием масштабируем подложку так, что 1 единица AutoCAD = 1 м.
5. `LEP-ROUTE` — черчение маршрута (полилиния), Enter — конец
   построения. Каждый новый маршрут получает свой уникальный ID
   (`LEP_ROUTE_0001`, `LEP_ROUTE_0002`...) — так линии к разным
   заявителям разделяются в будущей ведомости.
   - [ОТКРЫТО, НЕ РЕАЛИЗОВАНО] В конце построения маршрута нужно
     спрашивать, чем маршрут заканчивается: МТП+ЩУ или ПУ на опоре.
     Пока этого нет ни в одном файле.
6. `LEP-POLE` — РУЧНАЯ расстановка опор:
   - Пользователь кликает точку РЯДОМ с маршрутом (не обязательно
     точно в вершину).
   - Программа находит ближайшую точку НА линии маршрута, вставляет
     туда новую вершину полилинии и ставит блок опоры именно в неё.
   - Опора привязывается к вершине геометрической связью
     (`GEOMCONSTRAINT` / `GcCoincident`) — при перетаскивании опоры
     полилиния следует за ней.
   - При вставке каждой опоры — список выбора типа опоры (из
     справочника `*LEP-PoleTypes*` в `LEP-CONFIG.LSP`).
   - Тип опоры записывается в видимый атрибут блока — служит и
     подписью на чертеже, и источником данных для ведомости.
   - Enter без точки — выход из режима расстановки опор.
7. `LEP-SPAN` — клик по пролёту (участку между двумя соседними
   опорами):
   - Выбор типа линии: ВЛ (воздух) или КЛ (земля).
   - В зависимости от типа — выбор марки: для ВЛ — СИП-2 / СИП-3,
     для КЛ — кабель 120 мм² (марка пока неизвестна).
     Список марок — тоже во внешне-редактируемом справочнике
     (`LEP-CONFIG.LSP`, как и у опор), а не зашит в LEP-SPAN.LSP.
   - Длина пролёта считается автоматически (по геометрии, т.к.
     1 единица = 1 м после калибровки) и подписывается.
   - Слой/тип линии пролёта переключается визуально под ВЛ/КЛ —
     чтобы на ЧБ-распечатке было видно разницу даже без цвета.
8. `LEP-REPORT` — выгрузка ведомости в CSV, ОТДЕЛЬНО по каждому
   маршруту (по ID): кол-во опор по типам, метраж кабеля/провода по
   маркам, кол-во МТП/ЩУ/ПУ.

## Что уже сделано (на момент этой версии файла)

- LEP-SCALE — готово.
- LEP-ROUTE — готово (создание маршрута со своим ID).
- LEP-POLE — переделывается на ручную расстановку (эта версия).
- LEP-SPAN — старая версия красит весь маршрут одним выбором,
  требует переделки на нарезку по пролётам + вынос марок кабеля в
  CONFIG. НЕ СДЕЛАНО ЕЩЁ.
- LEP-REPORT — требует переделки без ActiveX (был написан под Windows,
  на Mac не запустится). НЕ СДЕЛАНО ЕЩЁ.
- Концовка маршрута (МТП+ЩУ / ПУ) — НЕ РЕАЛИЗОВАНО.

## Важное правило хранения файлов

DWG чертежа должен лежать В ТОЙ ЖЕ ПАПКЕ, что и все модули
`LEP-*.LSP`. Это не временный костыль, а теперь официальное правило:
на нём держится и поиск файлов (`findfile`), и автоматическая
регистрация папки как доверенной (`TRUSTEDPATHS`) в `LEP-START.LSP`.
Работает одинаково у любого пользователя на любой платформе (Mac/
Windows) без единой правки кода — при условии, что это правило
соблюдается.
